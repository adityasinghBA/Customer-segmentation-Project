# Customer Segmentation using RFM Analysis and KMeans Clustering

## Business Problem
The project helps businesses identify different customer groups based on purchasing behavior.

## Dataset Source
Dataset provided by Masai School.

## Dataset Description
The dataset contains customer transactions including quantity, invoice date, unit price, and customer ID.

## Tools & Libraries Used
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Steps Performed
1. Imported libraries
2. Loaded dataset
3. Data cleaning
4. Exploratory Data Analysis
5. Feature Engineering
6. Customer Segmentation using KMeans
7. Visualization
8. Business Insights

## Data Cleaning Summary
- Removed missing values
- Removed negative quantities
- Converted invoice date into datetime format

## Business Insights
- Identified high-value customers
- Segmented customers into groups
- Improved customer understanding

## Final Recommendations
Businesses should target high-value customers with loyalty programs and improve engagement for inactive customers.
